# STL → STEP 변환기

STL 메시 파일을 STEP(AP214) 솔리드로 바꾸는 작은 도구입니다. [OpenCascade](https://dev.opencascade.org/)(OCP 파이썬 바인딩)를 씁니다.
명령줄로도 쓸 수 있고, 내 PC에서 도는 웹페이지(끌어다 놓기)로도 쓸 수 있습니다. 파일은 외부로 전송되지 않습니다.

## 하는 일
1. STL 삼각형을 읽어 면으로 꿰맵니다 (sewing, 허용 오차 `--tol`).
2. 닫힌 껍질은 솔리드로 만듭니다 (덩어리가 여러 개여도 각각 처리).
3. 같은 평면에 있는 삼각형들을 큰 면 하나로 합칩니다 (`--no-merge`로 끔).
4. **원·원통 복원** (기본 켬, `--no-circles`로 끔): 구멍·보스·필렛·긴 구멍(슬롯)·관처럼
   원통인 곳을 찾아 **진짜 원통면 + 원/원호/타원 모서리**로 바꿉니다. 다른 CAD에서 원으로 보이고 지름을 잴 수 있습니다.
5. STEP 파일로 저장하고 삼각형 수·면 수·부피·형상 검사·원통면 수·지름을 알려 줍니다.

### 원·원통 복원은 어떻게 하나
- CAD가 내보낸 STL은 원통을 축과 나란한 길쭉한 띠(평면 조각)로 쪼갭니다. 같은 방향으로 이어진 띠들을
  축에 수직인 평면에 비추면 꺾은선이 되고, 이 꺾은선을 원호와 직선으로 나눕니다
  (원 맞춤 오차 `--fit-tol` 이내, 한 마디 50° 이하, 마디 3개 이상, 꺾임각이 원과 맞을 것).
- Fusion 360 처럼 위·아래 고리 꼭짓점이 엇갈린(개수도 다를 수 있는) 메시는 삼각형이 띠로 안 묶이므로, 매끈하게 이어진 삼각형 덩어리의 법선으로 축을 잡고 지그재그 순서로 꿴 꼭짓점을 같은 규칙으로 원호/직선으로 나눕니다(고리 평면 두 개, 고리마다 같은 간격일 것).
- 원호가 된 띠들은 원통면 하나로, 그 경계는 원·원호(축에 수직인 평면과 만날 때)·타원(비스듬한 평면)·직선으로 만듭니다.
- 결과를 OpenCascade 형상 검사와 부피 비교로 확인하고, 어긋나면 그 원통은 빼거나 파일 전체를
  예전 방식(삼각형)으로 저장합니다. 그래서 예전보다 나빠지지는 않습니다(출력에 "원 복원 안 함: 이유"가 나옴).

### 한계 (여전히 삼각형 조각인 것)
- 구(볼 끝, 필렛 모서리 꼭짓점), 원뿔(접시머리 자리, 모따기 원), 토러스·굽은 관·곡선 따라 쓴 필렛, 자유곡면(날개 단면 등).
- 거의 원에 가까운 자유곡선(예: 동체 단면 스플라인)은 원 맞춤 오차 이내면 반지름이 조금씩 다른 원통 조각 여러 개로 바뀔 수 있습니다(모양 오차는 `--fit-tol` 이내).
- 정다각형에 가까운 모양: 6각(60°)은 원으로 보지 않지만, 8각 이상 정다각형 기둥은 원통으로 바뀔 수 있습니다.
- 3D 스캔처럼 꼭짓점이 원 위에 정확히 있지 않은 메시, 원통이 위·아래 고리 두 개 사이 띠 하나로 쪼개지지 않은 메시(가운데에 꼭짓점이 더 있는 것)는 거의 복원되지 않습니다.
- 열린(구멍 난) 메시, 비다양체 메시는 원 복원을 건너뜁니다.

> 삼각형이 20만 개를 넘으면 수십 분 걸릴 수 있으니, 메시를 먼저 줄이는 것을 권합니다.

## 설치
Python 3.10 이상.
```bash
pip install -r requirements.txt
```

## 사용법

### 웹페이지
```bash
python stl_to_step_web.py              # http://127.0.0.1:8765 접속
python stl_to_step_web.py --host 0.0.0.0 --port 8765   # 같은 네트워크의 다른 기기(폰 등)에서 접속
```
STL을 끌어다 놓으면 변환되고 **STEP 받기** 버튼이 나타납니다. 여러 파일을 한꺼번에 넣을 수 있습니다(차례로 처리).

### 명령줄
```bash
python stl_to_step.py part.stl                    # part.step 생성
python stl_to_step.py a.stl b.stl -o out/         # 여러 개를 out/ 폴더로
python stl_to_step.py "parts/*.stl" -o out/       # 글롭 패턴
python stl_to_step.py part.stl -o result.step --tol 0.005
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `-o, --out` | 입력과 같은 폴더 | 출력 파일(`.step`) 또는 폴더 |
| `--tol` | `0.01` | 꿰매기 허용 오차 (mm) |
| `--no-merge` | 끔 | 면 합치기 생략 (빠르지만 면 수 = 삼각형 수) |
| `--no-circles` | 끔 | 원·원통 복원 끄기 (예전 방식) |
| `--fit-tol` | `0.01` | 원 맞춤 허용 오차 (mm). CAD에서 내보낸 STL이면 기본값으로 충분 |

출력 예:
```
OK  plate.stl -> plate.step | 삼각형 444 -> 면 10 | 덩어리 1 | 부피 15.0 cm3 | 0.1s | 원통면 4개 (지름 3, 5, 8, 12) | 메시 대비 부피 -0.06%
```
메시 대비 부피 차는 정상입니다(원통이 다각형보다 조금 커서/작아서).
웹페이지에는 **원·원통 복원** 체크 상자가 있습니다.

## 시험
```bash
python tests/make_test_parts.py      # build123d 로 정답 아는 부품 STL (tests/out/, git 에 안 올라감)
python tests/run_tests.py [다른.stl ...]   # 예전/새 방식 변환, STEP 다시 읽어 원통 지름·검사·부피 비교
```
변환 실패가 있으면 종료 코드 1을 돌려줍니다.

## 경고 메시지
- **열린 껍질 N개**: STL에 구멍이 있어 닫힌 솔리드가 안 됐습니다. 껍질(면 모음)로 저장됩니다. 메시 복구 도구로 구멍을 메운 뒤 다시 변환하세요.
- **형상 검사 불통과**: OpenCascade 형상 검사를 통과하지 못했습니다. `--tol` 값을 바꿔 보세요.
